# Search on site

A simple Chrome web extension that gives a shortcut to the "site:" syntax, see docs [here](https://support.google.com/websearch/answer/2466433?visit_id=639219846742095863-2969215252&p=adv_operators&hl=en-NL&rd=1#:~:text=To%20search%20for%20results%20from%20a%20specific%20site). 

Press `Ctrl+Alt+F` (or `Command+Alt+F`), type your query, press enter and you will navigate to the results page of your default search engine for the current site.
